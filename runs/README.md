# Run records

Start with [`tae_2026/README.md`](tae_2026/) for the current evidence map.

This directory is the teammate-facing navigation layer. Frozen scientific evidence remains in its canonical artifact directory; large activation archives and raw causal records remain in the verified local data archive. A run README may summarize and link evidence, but it does not replace or broaden a manifest, protocol, result, or conclusion.

## Conventions

- One independently executable or decision-bearing step per subfolder.
- `README.md`: purpose, status, result, evidence, and claim boundary.
- `run_record.json` where available: machine-readable pointer to canonical evidence.
- Failed and invalid runs stay visible. They are never overwritten by retries.
- Development, exploratory, and confirmation records stay explicitly separated.
