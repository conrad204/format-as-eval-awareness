**Figure.** Cross-format transfer gap collapses with matched-format-PCA erasure rank
while purpose AUC stays essentially flat, across all three checkpoints and all three
pinned depths, with payload-block-bootstrapped 95% confidence intervals.

Per-fold cross-fitted (5 held-out purpose-family folds) matched-format PCA erasure
(orth_basis(B, r), the un-averaged per-group evaluation/deployment x benchmark/casual
contrast basis) at ranks {0 (raw baseline), 1, 4, 16, 64}, retraining the same balanced
2x2 purpose probe on the erased activations. Computed on the uahpc cluster
(scripts/full320_v3_erasure_dose_response_bootstrap.py; N_BOOT=1000, blocks resampled
from the 320 payload blocks with replacement, no refitting in the bootstrap stage).
Point estimates match the earlier local-workstation run to 3-4 significant figures at
every shared condition (a consistency check, not re-derived).

Purpose AUC's 95% CI at rank 64 overlaps its raw-baseline CI at every depth and every
checkpoint (no detectable cost). The transfer gap's CI at rank 64 does NOT overlap the
raw-baseline CI in any of the 9 model x depth cells -- the gap collapse is outside
bootstrap noise, not merely a point-estimate trend.

Caveat, not shown in this figure: this erasure method does NOT drive format itself to
chance-level decodability (format_auc_after_erasure stays well above 0.5 at every rank
tested) -- see the null-projection and direction-geometry analyses in this same
results/ directory for why the gap still falls substantially despite incomplete format
erasure. This figure documents the raw dose-response only, not the mechanism.
